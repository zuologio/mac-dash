No buttons. Ever.

The panel follows your Mac on its own.

Mac sleeps or shuts down

The dashboard notices within seconds and turns the screen off, so the panel isn't glowing in a dark room.

Mac wakes or starts up

The first reading that arrives turns the screen back on. Nothing to press, nothing to restart.

Only the screen sleeps with your Mac. The Pi itself keeps running, ready to wake the panel. This works when the Pi is installed with --hdmi (or --backlight for panels with a backlight device). It also follows the Mac's display sleeping, even when the Mac itself stays awake.

How it works

1

Discover

The Pi announces itself on the LAN every 3 seconds. The Mac finds it on its own, even after a reboot.

2

Stream

Five times a second the agent sends one small UDP packet. A lost packet is replaced by the next.

3

Draw

The Pi paints the image itself and writes it to /dev/fb0, redrawing only what changed.

Prefer a terminal? There is also a text dashboard for SSH and Mac terminals. See the README.

Build your own

Everything used in the original build. The links are Amazon listings that may disappear, so each part is described well enough to search for an equivalent.

Parts

  1. Raspberry Pi Zero (W) running Raspberry Pi OS Lite, with no desktop environment. Any Pi or compatible board should work, but a bigger model may not fit inside the enclosure.
  2. 7-inch HDMI display, 1024×600. Listing. Search for: 7 inch 1024x600 HDMI IPS display. See the note below about its connector placement.
  3. 90° HDMI adapter for the display's HDMI input. Listing. Search for: HDMI right angle adapter, 90 degree. Needed because the port faces sideways and a straight plug sticks out too far.
  4. 90° power adapter for the display's power input. Listing. Search for: right angle USB adapter, matching your display's connector (micro-USB or USB-C). Same reason: the port is on the side.
  5. Mini-HDMI to HDMI adapter for the Pi Zero's video output. Listing. Search for: mini HDMI to HDMI adapter, short or angled. Short and compact keeps it inside the case.
  6. USB power splitter cable (one input, two outputs) to power the Pi and the display from a single cable. Listing. Search for: USB Y splitter power cable, or 1 to 2 micro-USB power cable.
  7. 4 M2.5 screws and 4 standoffs, 10 mm long, to mount the Pi inside the case. The standoffs are the little brass or yellowish spacers used on circuit boards, with a male thread on one end and a female thread (a hole) on the other. Search for: M2.5 male-female standoff 10mm (usually sold as a kit with screws).
  8. microSD card for the Pi, and a 5 V USB power supply that can run both devices.
  9. 3D-printed enclosure (files below).

About the screen. This display is not ideal. Its HDMI and power inputs are on the side, so it needed two 90° adapters, and the case had to grow around them. With the connectors on the back, no adapters would be needed and, more importantly, the bezels around the screen could be much smaller. If you pick a panel for this build, look for one with the ports on the back.

Steps

  1. Print the case and stand.
  2. Flash Raspberry Pi OS Lite (no desktop) and enable SSH.
  3. Install the agent on the Mac and the display on the Pi (see Run it).
  4. Connect the Pi to the panel with the mini-HDMI and 90° adapters, and power both from the splitter cable.
  5. Mount everything behind the panel and close the case.

Run it

Both machines on the same LAN.

Try it locally

cargo run --release -p macdash-agent   # Mac
cargo run --release -p macdash-tui     # anywhere on the LAN

Install on the Mac

./deploy/install-mac.sh

Install on the Pi

cargo install cross --git https://github.com/cross-rs/cross
./deploy/build-pi.sh        # --zero2 for a Zero 2 W
./deploy/install-pi.sh pi@192.168.0.148 --hdmi

The dashboard starts at boot with no keyboard, and finds the Mac by itself. All flags are in the README.
